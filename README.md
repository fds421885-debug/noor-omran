# مسابقة نور البيان (1448 - 1449 هـ) 📖✨ (React SPA | ثيم دولينجو المبهج)

منصة تفاعلية متكاملة مبنية بـ **React 19** و **Vite** و **TypeScript** مع أسلوب وتصميم دولينجو المبهج وقاعدة بيانات **Firebase Cloud Firestore**.

---

## 🎨 المميزات المعمارية والتقنية
- **إعادة بناء حديثة بالكامل بـ React و TypeScript**:
  - هيكلة معمارية نقية قائمة على المكونات (Component-driven) ومزودة بسياق مركزي موحد (`AppContext`).
  - معالجة وإصلاح مشكلة تكرار لافتات الفقرات الأربع في بطولات الفرق، مع ضبط وتزامن المؤقت والأسئلة لجميع المتصلين لحظياً.
- **إدارة الأدوار الأربعة (Multi-Role Support)**:
  - **المشرف العام** (`supervisor`): المشرف المعتمد فضيلة الشيخ **محمد منتصر محمد يونس**.
  - **لجنة التحكيم والمعلمون** (`teacher`): تقييم شفهي وتلاوة لحظية مع احتساب المتوسط الحسابي.
  - **شاشة العرض المباشر / المسرح** (`presenter`): وضع الشاشات الكبيرة والمسرح الحي.
  - **الطلاب المشاركون** (`student`): التدريب الذاتي، الانضمام للمسابقات الحية برمز الغرفة، ولوحة الشرف.

---

## 🏆 نظام بطولات وتصفيات الفرق التفاعلي
- **الفقرات الأربع الموزعة بالتساوي**:
  1. الفقرة الأولى: المواجهة السريعة.
  2. الفقرة الثانية: تحدي الإتقان والتجويد.
  3. الفقرة الثالثة: سباق الذكاء والترتيب.
  4. الفقرة الرابعة: الجولة الحاسمة والتتويج.
- **تزامن كامل عبر السحابة (Firestore onSnapshot)** يضمن ظهور الأسئلة واللافتات في نفس اللحظة للمشرف والمعلمين والطلاب.
- **القرعة العادل للطلاب (Fair Round-Robin)** لمنع تكرار نفس الطالب حتى يشارك جميع أعضاء الفريق بالتساوي.
- **حفل التتويج والكأس النهائي** مع منصة التتويج والمؤثرات الاحتفالية والأرشفة التلقائية.

---

## ⚡ محرك النقاط والبطاقات التكتيكية الـ 40
- **محرك نقاط موحد (Idempotent Scoring Engine)** يمنع التكرار واحتساب نفس السؤال مرتين.
- **بنك الـ 40 بطاقة تكتيكية كاملة** مع فلاتر التوافق (الوقت، الأسئلة الشفهية، الترتيب، التوصيل، المضاعفة الذهبية، ودرع الأمان).
