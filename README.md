# مسابقة نور البيان (1448 - 1449 هـ) 📖✨ (ثيم دولينجو | Duolingo Theme)

موقع تفاعلي مبهج صُمم بـ **ثيم دولينجو العصري (Duolingo Style System)** لـ «مسابقة نور البيان للعام الهجري 1448 - 1449 هـ»، مع ألوان دولينجو المميزة والأزرار ثلاثية الأبعاد التفاعلية وقاعدة بيانات **Firebase Firestore**.

---

## 🎨 مميزات وتفاصيل التصميم الحالي
- **أيقونة الشعار الرسمية**: تم اعتماد **المصحف الشريف** (`fa-book-quran`) في الهيدر الرئيسي والبطاقات الترحيبية.
- **خلفية حية تفاعلية بأسلوب دولينجو (Geometric Duolingo Canvas)**:
  - جزيئات هندسية مبهجة: **مربعات، ومثلثات، ودوائر** تطفو وتدور بنعومة نحو الأعلى بألوان دولينجو الرسمية (الأخضر، الأصفر، الأزرق، والأحمر).
  - تتفاعل الأشكال لحظياً مع حركة مؤشر الفأرة ولمس الشاشة بالإصبع مع أمواج دائرية ناعمة عند النقر.
- **واجهة مستخدم نظيفة وخالية من التشتيت**:
  - تم إزالة شخصية الأسد وأي صور إضافية ليكون التركيز تاماً على المحتوى القرآني الأنيق.
  - تم إزالة عناصر النقاط والصحة في الهيدر، والإبقاء فقط على الشعار وزر التحكم بالصوت وحالة المستخدم عند تسجيل الدخول.
- **الأزرار ثلاثية الأبعاد (3D Chunky Buttons)**:
  - أزرار مجسمة بارزة تنضغط للأسفل عند النقر عليها بصوت ممتع يحاكي تجربة دولينجو.
- **شريط تقدم اكتمال الاسم (Progress Bar)**:
  - شريط تقدم ممتلئ بأسلوب دولينجو يعرض نسبة اكتمال الاسم الرباعي (0%، 25%، 50%، 75%، 100%).
- **مسار المراحل التفاعلي (Duolingo Learning Path)**:
  - استعراض فروع المسابقة الثلاثة (المستوى الأول، الثاني، الثالث) كحلقات ومحطات تفاعلية متصلة.
- **مؤثرات صوتية تفاعلية (`audio-fx.js`)**:
  - نقرات مرحة ونغمة نجاح وفوز كلاسيكية لدولينجو عند الدخول مع زر كتم/تشغيل الصوت.

## ✨ المميزات ومنطق النظام

1. **الواجهة الرئيسية الترحيبية**:
   - عنوان بارز: **مسابقة نور البيان 1448 - 1449**.
   - بطاقة إسلامية مزخرفة بالبسملة وشعار المسابقة.
   - زر تفاعلي مضيء ومتحرك بعنوان **"أبدأ"** ينقل المستخدم بسلاسة إلى شاشة التسجيل.

2. **تسجيل الدخول والتحقق الإلزامي من الاسم الرباعي**:
   - حقل إدخال مخصص مع عداد لحظي ذكي يحسب عدد الأسماء المكتوبة (`0 / 4 أسماء`).
   - شرط إلزامي: لا يقبل النظام الدخول إلا إذا كتب المتسابق **أربعة أسماء على الأقل** (الاسم الأول، اسم الأب، اسم الجد، اللقب/العائلة).
   - تنبيهات واضحة في حال كتابة أقل من 4 أسماء.

3. **التعرف الذكي على المشرف العام والترحيب المخصص**:
   - المشرف المعتمد على البرنامج: **منتصر ممد راغب يونس** (مع التوافق الذكي لأي فروق إملائية مثل صيغة محمد أو الفراغات والهمزات).
   - المشرف هو الوحيد الذي يظهر له:
     - عند أول دخول: **«أهلاً بك أيها المشرف»**
     - عند تكرار الدخول: **«مرحباً بعودتك أيها المشرف»**
   - سائر المسجلين يتم تصنيفهم كـ **طلاب مشاركين**:
     - عند أول دخول: **«أهلاً بك أيها الطالب»**
     - عند تكرار الدخول: **«مرحباً بعودتك أيها الطالب»**

4. **لوحة تحكم المشرف**:
   - إحصائيات حية: إجمالي الطلاب، الطلاب الجدد، عدد زيارات المشرف.
   - جدول متكامل لبيانات الطلاب المسجلين يُسحب مباشرة من فايربيس (Firestore).
   - ميزة البحث الفوري بالاسم داخل السجل.
   - إمكانية تحديث البيانات لحظياً.

5. **بوابة الطالب المشارك**:
   - بطاقة اعتماد رسمية برقم الزيارة وتاريخ التسجيل.
   - استعراض فروع المسابقة الثلاثة (المستوى الأول، المستوى الثاني، المستوى الثالث).
   - إرشادات وتوجيهات المسابقة.

6. **الربط مع قاعدة بيانات Firebase**:
   - الربط بمشروع: `mosapqt-al-tohfa`.
   - استخدام مجموعة `participants` لتخزين وحفظ كل متسابق مع عدد مرات زيارته وتاريخ أول وآخر تسجيل.
   - تفعيل وضع الحماية والنسخ الاحتياطي الذاتي (Offline Fallback) بحيث يعمل النظام بسلاسة في حال انقطاع الشبكة.

## 🚀 كيفية تشغيل المشروع

### الطريقة الأولى: التشغيل المباشر عبر السيرفر المحلي السريع (Vite)
في موجه الأوامر (Terminal / PowerShell) داخل مجلد المشروع:
```bash
npm start
```
أو:
```bash
npm run dev
```
سيفتح الموقع فوراً على الرابط المحلي: `http://localhost:5173`.

### الطريقة الثانية: فتح الموقع عبر أي سيرفر ويب ثابت (Static Server)
يمكن فتح ملف `index.html` عبر أي خادم ويب مثل Live Server في VS Code، أو:
```bash
npx serve .
```

## 🌐 النشر والاستضافة على Netlify و GitHub Pages (يعمل 100% بنقرة واحدة)

### 1. النشر على Netlify (نتفلاي):
- **الطريقة الأولى (الأسهل عبر السحب والإفلات Netlify Drop):**
  1. قم بتشغيل أمر البناء: `npm run build`
  2. اسحب مجلد `dist` فقط وأفلته في [Netlify Drop](https://app.netlify.com/drop). سيعمل موقعك فوراً بالكامل!
- **الطريقة الثانية (الربط المباشر بمستودع Git / GitHub):**
  - تم تجهيز ملف `netlify.toml` مسبقاً في المشروع. بمجرد ربط المستودع، سيتعرف Netlify تلقائياً على أمر البناء `npm run build` ومجلد النشر `dist` وقواعد التوجيه `_redirects` ويعمل 100%.

### 2. النشر على GitHub Pages (جيت):
- تم تضمين سير عمل GitHub Actions تلقائي (`.github/workflows/deploy.yml`). بمجرد رفع الكود إلى فرع `main` أو `master` وتفعيل Pages من إعدادات المستودع (Settings -> Pages -> GitHub Actions)، سيتم بناء ونشر الموقع تلقائياً.
- تم أيضاً إضافة خريطة استيراد (Import Map) مدمجة في `index.html` بحيث يعمل التطبيق حتى لو تم رفعه كملفات ثابتة بدون بناء!
