# خطة معالجة مشكلة حذف الاختبارات وتراجع التعديلات في بنك الاختبارات

## 1. تحليل المشكلة وأسبابها الجذرية (Root Cause Analysis)

1. **سبب اختفاء الاختبار الجديد فور إنشائه بعد حذف اختبار سابق:**
   - عند حذف اختبار، يتم تسجيل معرّفه في قائمة `nour_deleted_quizzes` المحلية وفي وثيقة `quizzes_config` بالسحابة.
   - في محرر الاختبارات، إذا كان `editQuizId` محتفظاً بمعرّف الاختبار المحذوف أو حدث تداخل في المعرفات المؤقتة، يتم حفظ الاختبار الجديد بنفس المعرف المصنف كمحذوف، فتقوم دالة `onSnapshot` و `loadCloudData` بحذفه واستبعاده فوراً.
   - بالإضافة إلى ذلك، هناك سباق تزامن (Race Condition) بين لحظة حفظ الاختبار في `quizzesCache` ولحظة وصول تحديث Firestore عبر `onSnapshot` و `loadCloudData`؛ حيث تبدأ مصفوفة الدمج `mergedQuizzes` بنسخة السحابة، وإذا لم تكن السحابة قد استلمت المستند بعد، يُحذف الاختبار الجديد من الذاكرة المحلية وتعود القائمة فارغة.

2. **سبب فقدان التعديلات ورجوع الاختبار للنسخة القديمة بعد الحفظ:**
   - عند حفظ أي تعديل في محرر الاختبارات، يتم إرسال التعديل مع خاصية `{ merge: true }` واستدعاء `serverTimestamp()`.
   - في دالتي `onSnapshot` و `loadCloudData`:
     ```javascript
     const localTime = localQ.updatedAt || 0;
     const cloudTime = cloudQ.updatedAt || (cloudQ.lastUpdated?.toMillis ? cloudQ.lastUpdated.toMillis() : 0);
     if (localTime > cloudTime) { ... }
     ```
   - عندما تعيد السحابة الوثيقة، يكون `cloudTime` مساوياً أو أكبر من `localTime`، فتتجاهل خوارزمية الدمج التعديل المحلي الأحدث `localQ` وتستبدله بـ `cloudQ` (النسخة السابقة)، مما يؤدي لضياع التعديلات ورجوع الاختبار للنسخة القديمة فوراً.
   - استخدام `{ merge: true }` عند حفظ الأقسام والأسئلة يمنع حذف الأسئلة التي ألغاها المشرف ويُبقي الحقول القديمة مشوشة.

## 2. خطوات الحل المقترحة (Action Plan)

### المرحلة الأولى: تحصين معرفات الاختبارات وإلغاء التداخل مع المحذوفات
1. توليد معرفات عشوائية فريدة ومحصنة تماماً للاختبارات الجديدة:
   `"quiz_" + Date.now() + "_" + Math.random().toString(36).slice(2, 7)`
2. تنظيف حقل `editQuizId` إجبارياً عند فتح محرر الاختبارات الجديد، وعند حذف أي اختبار، وعند إغلاق النافذة.
3. التأكد التام من إزالة معرّف الاختبار المحفوظ فورياً من قوائم المحذوفات المحلية والسحابية (`deletedQuizIds` و `nour_deleted_quizzes`).

### المرحلة الثانية: تصحيح خوارزمية حفظ الاختبارات ومزامنتها سحابياً
1. تحديث دالة `syncQuizToCloud`:
   - حفظ الوثيقة كاملة بدقة بدون دمج غير منضبط `{ merge: true }` لضمان أن التعديلات (تعديل الأسئلة، حذف أسئلة، تغيير النصوص والخيارات) تُحفظ بدقة كما حددها المشرف.
   - ضمان تضمين `updatedAt: Date.now()` بشكل إلزامي ودائم في كل حفظ.
2. إضافة حماية ضد السباق (Pending Save Lock):
   - تسجيل أي اختبار جاري حفظه في قائمة أو قفل زمني محلي يمنع `onSnapshot` و `loadCloudData` من الكتابة فوقه بنسخة قديمة قبل اكتمال الاستقرار.

### المرحلة الثالثة: إصلاح خوارزمية الدمج في `onSnapshot` و `loadCloudData`
1. تعديل شرط المقارنة بين النسخة المحلية والسحابية:
   - اعتماد التعديل المحلي دائماً إذا كان تاريخه أحدث أو مساوياً مع وجود تعديلات معلقة.
   - عدم السماح بحذف أي اختبار موجود في الكاش المحلي لمجرد أنه لم يصل للسحابة بعد (Optimistic Local-First).
2. منع حذف التعديلات المتعددة المتتالية (بحيث يمكن للمشرف إجراء عدة تعديلات متتابعة وحفظها دون أي تعارض).

### المرحلة الرابعة: التحقق والاختبار
1. اختبار دورة حذف اختبار ثم إنشاء اختبار جديد يدوي، والتأكد من بقائه في القائمة ومزامنته مع Firestore.
2. اختبار فتح اختبار موجود، إجراء تعديلات متعددة (تعديل عنوان، نصوص أسئلة، درجات، خيارات)، وحفظها، والتأكد من بقائها بدقة دون أي ارتداد للنسخة القديمة.
3. التحقق من تشغيل `npm run lint` والتأكد من عدم وجود أي أخطاء برمجية.
