# خطة التحديث الشاملة لتناسق الجوال وإدارة الغرف ومواجهات الفرق

## 1. إتاحة خروج ومغادرة سلسة وفورية لمنشئ الغرفة والمشرف وجميع الأدوار
- [x] إضافة زر مغادرة سريع في نافذة اختيار الفرق داخل المسرح (`#btnExitFromTeamPicker`).
- [x] إضافة زر مغادرة سريع في شاشة العرض السينمائي لمواجهة الفرق (`#btnEntranceExitRoom`).
- [x] إضافة خيار "مغادرة الغرفة والعودة للوحة التحكم" في نافذة مغادرة المشرف (`#btnLeaderLeaveKeepRoom`) مع إبقاء الغرفة مفتوحة ونشطة في السحابة.
- [x] بناء دالة موحدة ونظيفة `executeLeaveRoomSafely` لتنظيف كافة العدادات، النوافذ المعلقة، والمزامنة السحابية عند المغادرة.
- [x] **حل مشكلة عدم عمل زر مغادرة الغرفة نهائياً**:
  - إنشاء معالج شامل وموحد `window.handleLeaveRoomRequest` مع ربط مباشر (`onclick`) ومستمعات أحداث وتفويض عام على مستوى الوثيقة (`document click delegation`).
  - إضافة مودال مغادرة فوري وأنيق (`#roomExitConfirmModal`) بطبقة عليا فائقة (`z-index: 100060`) لمنع حجب النافذة خلف أي طبقات أو نوافذ منبثقة أخرى.
  - إتاحة خيار المغادرة الفورية والعودة للوحة التحكم دون أي تعقيدات أو اشتراط تسليم القيادة، مع خيار اختياري للمشرف لإنهاء المسابقة للجميع.

## 2. تناسق هيدر المسرح الحي والعناصر المحيطة بزر المغادرة
- [x] إعادة هيكلة شريط الرأس `.arena-top-bar` إلى مجموعتين متناسقتين:
  - مجموعة الشارات (`.arena-status-badges-group`): تشمل شارة المتواجدين وشارة دور المستخدم بحدود ثلاثية الأبعاد وارتفاع موحد.
  - مجموعة الأزرار (`.arena-actions-buttons-group`): تشمل زر إعدادات المسابقة وزر مغادرة الغرفة وزر العودة لاختيار الفرق.
- [x] تصميم كلاس دولينجو مخصص للأزرار التحذيرية والمغادرة (`.btn-duo-exit`) بلون أحمر ثلاثي الأبعاد مبهج وحدود ناعمة وتأثير نقر حركي.
- [x] ضبط تناسق شريط الرأس على شاشات الجوال:
  - السطر الأول: عنوان الغرفة ورمزها مع خط فاصل منقط.
  - السطر الثاني: شارات الحالة مقسمة بالتساوي 50% - 50% بارتفاع متناسق.
  - السطر الثالث: أزرار الإجراءات بمساحة لمس مريحة (44px) ومحاذاة مثالية دون أي تداخل أو قص.
- [x] استبدال التموضع المطلق في نافذة اختيار الفرق بشريط مرن `.team-picker-top-bar` يضع الشارة وزر المغادرة في نسق متوازن ومستقر.
